# PoE2 日本語化 用語集

翻訳の表記揺れを防ぐためのプロジェクト統一辞書。**poe2db.tw/jp の表記を一次基準**とするが、明らかに自然でないものは override する。

## 採用ルール

1. poe2db 表記が自然 → そのまま採用
2. poe2db 表記が違和感 → override 候補として「採用語」欄に記載、`docs/ja/_overrides/` で上書き予定
3. PoE1 日本語コミュニティの慣例語が定着している場合は優先
4. カタカナと漢字混在を許容（プレイヤーの感覚に近づける）

## 表記スタイル

### 数値・記号

- **数値**: 半角英数字を使用（`100%` ◯、`１００％` ✕）
- **記号**: コロン・カンマ・括弧は半角優先（`Damage: 100` ◯、`Damage：100` 要文脈判断）
- **百分率**: `%` 半角統一
- **範囲表記**: `(5-10)` または `5～10`（poe2db は「—」を使うこともある）

### 文体

- **ボタン/ラベル**: 体言止め
  - 例: `Save` → `保存`、`Options` → `オプション`
- **ダイアログ本文**: ですます調
  - 例: `Are you sure?` → `本当によろしいですか？`
- **エラーメッセージ**: ですます調 + 客観表現
  - 例: `File not found` → `ファイルが見つかりません`
- **ツールチップ**: 簡潔に体言止め or です調どちらでも可

### カタカナと漢字の使い分け

- **ゲーム固有用語**: カタカナ優先（モッド、ジェム、ティア、フラスコ、アンプル）
- **一般用語**: 漢字優先（攻撃、防御、火、冷気、物理、元素）
- **混在 OK**: 「火ダメージ増加」「マナ消費削減」など自然な日本語を優先
